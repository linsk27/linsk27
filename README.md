## 项目原则

- 可运行：README 里给出明确入口和本地启动路径。
- 可判断：项目说明先讲解决什么问题，再讲技术栈。
- 可展示：重点项目保留截图、模拟图或可访问演示。
- 可维护：文档里写清边界，不把实验项目包装成生产系统。
